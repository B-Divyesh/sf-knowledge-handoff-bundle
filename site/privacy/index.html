Privacy

Privacy

Knowledge Handoff Bundle works without sending your project data to this website.

Landing site

This website has no analytics, advertising, cookies, third-party scripts, or remote fonts.

The landing page leaves localStorage, sessionStorage, and IndexedDB empty. Its service worker caches site files for offline use.

The hosting provider may retain ordinary server access logs for security and reliability.

CLI and generated bundles

The CLI has no telemetry. It reads files you list and writes to the output path you choose.

Public URL checks run only with --check-links. The checker rejects credentials and checks only listed URLs and each origin’s robots.txt.

Recipient review state

A generated bundle stores reviewed artifact IDs in that recipient browser. This state never leaves the browser.

Export acknowledgement creates a local JSON download. It does not upload the receipt.

Your control

Delete a generated bundle like any other folder. Clear browser site data to remove saved review state.

Questions can be raised through the project’s public GitHub repository.
