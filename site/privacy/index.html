Plain-language policy · August 27, 2026

Privacy

Knowledge Handoff Bundle is designed to work without sending your project data anywhere.

Landing site

This website has no analytics, advertising, cookies, third-party scripts, or remote fonts. The hosting provider may retain ordinary server access logs for security and reliability.

CLI and generated bundles

The CLI has no telemetry. It reads files you explicitly list and writes only to the output path you choose. Public URL checks happen only when you pass --check-links. The checker does not accept credentials and does not crawl beyond the exact links and each origin’s robots.txt.

Recipient review state

A generated bundle stores reviewed artifact IDs in the recipient browser’s local storage. This state never leaves that browser. “Export acknowledgement” creates a local JSON download; it does not upload the receipt.

Your control

Delete a generated bundle like any other folder. Clear the browser’s site data to remove saved review state. Questions can be raised through the project’s public GitHub repository.
